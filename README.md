# Anagat AI Solutions website

A responsive, buildless first draft with Home, Our services, Portfolio, Founders and Contact pages.

## Local preview

Run `python3 -m http.server 8000 --bind 127.0.0.1` from this directory, then open http://127.0.0.1:8000.

## Content to complete

- Mayank's LinkedIn and any additional founder portfolio links.
- Confirm that professional roles from the supplied pitch deck are current before launch.

Contact uses email, phone and WhatsApp links; no form backend is required. No dependencies or build step. All five HTML pages can be served by any static host.

## Design revision

Uses locally hosted Inter Variable, based on InScene typography. Founder photos supplied by the user. Five product illustrations created with built-in ImageGen; prompts are in assets/IMAGE-PROMPTS.md.

Service terminology reference: https://thoughtbot.com/services and Microsoft Learn RAG documentation.

The home-page customer quotes are explicitly illustrative draft placeholders and must be replaced with approved customer feedback before public launch. Payment tags describe existing checkout functionality; international payment support has not been verified.
